# Slide 13: The Three Waves of AI

## Core Message
**From Analysis to Creation to Action**

### 1. Objective
To contextualize the current technological moment. We are entering the "Third Wave" of AI. Understanding this evolution helps in predicting the capabilities and limitations of the technology.

### 2. Critical Analysis & Rationale
*   **The Economic Multiplier:** Predictive AI optimizes existing processes (10%). Generative AI creates new content (100%). Agentic AI replaces labor (1000%). The economic value grows exponentially with each wave.
*   **The Agency Leap:** The leap from Wave 2 (GenAI) to Wave 3 (Agentic) is the leap from "Passive" to "Active."

### 3. Step-by-Step Explanation

#### a. Basic Insights
1.  **Wave 1: Predictive AI (The Analyst).** Machine Learning. It looks at data and says "This is a cat" or "Stock will go up." It classifies and predicts. (Era: 2010-2022).
2.  **Wave 2: Generative AI (The Creator).** LLMs. It looks at a prompt and says "Here is a poem" or "Here is an image." It creates new data. (Era: 2022-2024).
3.  **Wave 3: Agentic AI (The Worker).** LAMs. It looks at a goal and says "I have completed the task." It takes action in the real world. (Era: 2025-Present).

#### b. Advanced Insights
*   **The Value Multiplier:**
    *   Predictive = Information.
    *   Generative = Content.
    *   Agentic = **Labor**.
    *   *Labor is worth significantly more than Content or Information.*
*   **The Feedback Loop:**
    *   Wave 1 & 2 are "Open Loop" (Input -> Output).
    *   Wave 3 is "Closed Loop" (Input -> Action -> Result -> Correction -> Output). The ability to *self-correct* is the defining feature of the Third Wave.

### 4. When to Use?
*   **Investment Strategy:** Don't invest in "Content Generation" (Wave 2 is commoditizing). Invest in "Process Automation" (Wave 3).
*   **Tech Stack Selection:** Are you using a "Chat" interface (Wave 2) or a "Background Worker" interface (Wave 3)?

### 5. Examples

#### a. Basic (Writing)
*   *Wave 1:* Grammarly (Predicts errors).
*   *Wave 2:* ChatGPT (Writes the essay).
*   *Wave 3:* Research Agent (Reads 5 books, writes the essay, emails it to the professor, and revisions it based on feedback).

#### b. Intermediate (Coding)
*   *Wave 1:* IntelliSense (Predicts next variable).
*   *Wave 2:* Copilot (Generates a function).
*   *Wave 3:* Devin/Claude Code (Builds the entire app, runs tests, fixes bugs, and deploys).

#### c. PhD / Advanced (Scientific Discovery)
*   *Wave 1:* AlphaFold (Predicts protein structure).
*   *Wave 2:* Generative Chemistry (Invents new molecules).
*   *Wave 3:* Lab Agent (Controls the robotic pipette, synthesizes the molecule, measures the result, updates the hypothesis, and repeats).

### 6. Implementation in Agentic AI
*   **Architecture Change:**
    *   Wave 2 App: `User -> Prompt -> LLM -> Response`.
    *   Wave 3 App: `User -> Goal -> Agent -> [Loop: Plan, Tool, Observe] -> Result`.
*   **Latency:** Wave 3 is slower (multi-step). You must design UX for asynchronous "work," not synchronous "chat."

### 7. Why This Matters?
*   **Expectation Management:** People expect Wave 3 results from Wave 2 tools (e.g., expecting ChatGPT to write a perfect book in one shot). It fails because it lacks the "Loop."
*   **Economic Impact:** Wave 3 is where the "Trillion Dollar" value unlocking happens (Digital FTEs).

### 8. What Problem Does It Solve?
*   **The "Hallucination" Problem:** Wave 3 solves hallucination via *verification*. It can run the code, see the error, and fix it. Wave 2 just guesses.

### 9. Architecture Deep Dive
*   **The Loop Architecture:**
    *   **OODA:** Observe (Input), Orient (Context), Decide (Plan), Act (Tool).
    *   **ReAct Pattern:** Reason + Act. The foundational paper for Wave 3.

### 10. Common Practices & Pitfalls
*   **Pitfall:** Using Wave 2 metrics for Wave 3.
    *   *Correction:* Don't measure "Tokens per second." Measure "Success rate per task." An agent that takes 5 minutes but works is better than a generator that takes 1 second and lies.
*   **Practice:** "Give it tools." An agent without tools is just a Wave 2 chatbot.

### 11. Reflection Questions
1.  *Are you building a 'Chatbot' (Wave 2) or an 'Employee' (Wave 3)?*
2.  *How does your business model change when you stop selling 'Content' and start selling 'Work'?*
