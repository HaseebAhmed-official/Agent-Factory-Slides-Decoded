### Strategic Deep Dive (GEMINI.md Extensions)

#### 1. Objective
To visualize the "Supply Chain" of the Agent Factory.

#### 2. Step-by-Step Explanation
*   **Basic Insights:** Head -> File -> Cloud -> Cash.
*   **Advanced Insights:** **The Bottleneck is Extraction.** The hardest part is getting the expert to explain *how* they do what they do. This requires "Knowledge Engineering" interview techniques.

#### 3. Examples
*   **Basic:** Writing down steps.
*   **Intermediate:** Recording screen sharing of a task and using AI to convert to steps.
*   **PhD / Advanced:** **Imitation Learning.** Letting an Agent "watch" the human work for a week (logging keystrokes/pixels) and automatically inducing the `SKILL.md` from the logs.

#### 4. Implementation in Agentic AI
*   **Tool:** `Loom` -> `Transcript` -> `Claude` -> `SKILL.md`.

#### 5. Why This Matters?
*   **Scalability:** You can't scale a guru. You can scale a file.

#### 6. Architecture Deep Dive
*   **The Studio:** A dev environment specifically for "Authoring" skills.
