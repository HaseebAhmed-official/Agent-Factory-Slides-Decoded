# Slide 39: Skills are Just Folders

## Core Message
**The Simplicity of Agency: Folders as Logic Containers**

### 1. Objective
To demystify the technology behind "Agentic AI." By reducing "High-Value Expertise" to simple "Folders and Files," we lower the entry barrier for Subject Matter Experts (SMEs).

### 2. Critical Analysis & Rationale
*   **Low-Code isn't enough; No-Code is too rigid.** "Folder-Code" is the middle ground. It uses the most robust API in history: The File System.
*   **Human-Centric Design:** Humans have used folders to organize work for 40 years. By mapping AI skills to folders, we leverage existing mental models.

### 3. Step-by-Step Explanation

#### a. Basic Insights
*   **Structure:** A Skill is not a database entry; it's a directory.
*   **Contents:** `SKILL.md` (The Head), `docs/` (The Memory), `tools/` (The Hands).
*   **Accessibility:** If you can create a folder on your Mac or Windows, you can build an AI Agent.

#### b. Advanced Insights (Deeper Look)
*   **Git-Native Logic:** Because Skills are folders, they are natively compatible with Git. You can "Branch," "Merge," and "Pull Request" an employee's job description.
*   **Atomic Portability:** You can `.zip` an entire professional role and email it. This is **Knowledge Liquidity**.
*   **Auditable Traceability:** Managers can open the folder and read exactly what the AI was "told" to do. No hidden layers, no weights, no black box. Just Markdown.

### 4. When to Use?
*   **Project Initialization:** When creating a new capability for your factory.
*   **Open Source Sharing:** Publishing "Expertise Packs" on GitHub.

### 5. Examples

#### a. Basic (The 'Brand Guidelines' Skill)
*   *Folder:* `anthropic_brand/`
*   *File:* `SKILL.md` (Contains hex codes and font names).
*   *Action:* Agent reads folder and formats every document correctly.

#### b. Intermediate (The 'Legal Researcher' Skill)
*   *Folder:* `legal_audit/`
*   *Sub-folder:* `docs/` (Contains current labor laws).
*   *Script:* `check_compliance.py` (Checks contract text against docs).

#### c. PhD / Advanced (The Distributed Workforce)
*   *Concept:* **Content-Addressed Expertise.**
*   *Scenario:* Skills are stored on a decentralized network (like IPFS). When an agent is spawned, it doesn't "download" code; it "mounts" a specific hash representing a verified Skill folder. This ensures the agent is using the exact, untampered logic required for a high-security task (e.g., Nuclear Plant Maintenance).

### 6. Implementation in Agentic AI
*   **Logic:** `agent.mount_skill('./skills/marketing')`.
*   **Discovery:** The agent runs `find ./skills -name "SKILL.md"` to see what it can do.

### 7. Why This Matters?
*   **Maintenance:** It is easier to update a Markdown file than to retrain a model.
*   **Ownership:** You own the folder. You own the IP.

### 8. What Problem Does It Solve?
*   **The "Stuck in the Cloud" Problem:** Most AI logic is trapped in the web interfaces of OpenAI or Anthropic. "Folders" bring the logic back to your local infrastructure.

### 9. Architecture Deep Dive
*   **The File-Based State Machine:**
    1.  `SKILL.md` defines the state.
    2.  `scripts/` handle transitions.
    3.  `output/` stores results.

### 10. Common Practices & Pitfalls
*   **Pitfall:** Nested folders that are too deep.
    *   *Correction:* Keep it flat. One level of sub-folders is enough.
*   **Practice:** Use "README-first" development. Write the `SKILL.md` before the scripts.
