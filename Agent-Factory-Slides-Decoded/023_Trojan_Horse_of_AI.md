# Slide 23: The "Trojan Horse" of AI

## Core Message
**Why 'Claude Code' is Actually a General Agent**

### Detailed Analysis (Original Context)

#### 1. The Misconception
Many people think "Claude Code" is just a tool for software engineers (like a better autocomplete). This slide argues that's a mistake.

#### 2. The Reality
Claude Code is an **Autonomous Problem Solver** that happens to speak the language of code.

#### 3. The Distinction
*   **Coding Agents (e.g., Cursor):** Role-bound to software development. They help you write code *faster*.
*   **General Agents (Claude Code):** Role-unbound. They solve problems across **any domain** using code as the universal interface.

#### 4. The "Trojan Horse" Analogy
*   Just as the Greeks used a horse to enter Troy, Anthropic uses "Code" to enter the computer, but the ultimate goal is **General Agency**.
*   **Quote:** "Calling it a 'Coding Agent' is like calling a CEO an 'Email Writer' just because they use email to do their job."

### Strategic Deep Dive (GEMINI.md Extensions)

#### 1. Objective
To reveal the hidden strategy behind "Coding Agents." Tools marketed as "Developer Tools" are actually "General Reasoning Engines" capable of solving *any* business problem.

#### 2. Step-by-Step Explanation
*   **Basic Insights:** The Trojan Horse allows General Agents into the enterprise under the guise of "Dev Tools."
*   **Advanced Insights:** **Turing Completeness.** A Coding Agent can execute *any* computation. **The IT Bypass:** IT blocks ChatGPT but allows VS Code extensions. The Coding Agent sneaks in. **The Pivot:** Once inside, it does non-coding work (Data Science, Ops) because those are just "Code + Data."

#### 3. Examples
*   **Basic:** Chatbot guesses Fibonacci. Trojan Horse writes Python to calculate it correctly.
*   **Intermediate:** Chatbot can't read 1GB CSV. Trojan Horse writes a stream-processing script to clean and summarize it.
*   **PhD / Advanced:** **Self-Replication.** A Coding Agent monitoring server health notices a missing feature, writes code for a new microservice, deploys it, and updates its own config to use it.

#### 4. Implementation in Agentic AI
*   **The Sandbox:** The key enabler is the Code Execution Environment.

#### 5. Why This Matters?
*   **Strategic Advantage:** Companies banning AI but allowing Dev Tools are allowing AI anyway.
*   **Universal Interface:** Validates the thesis that Code is the universal interface.

#### 6. Architecture Deep Dive
*   **Dual-Mode:** Chat Mode (NLP) + Exec Mode (Runtime).
