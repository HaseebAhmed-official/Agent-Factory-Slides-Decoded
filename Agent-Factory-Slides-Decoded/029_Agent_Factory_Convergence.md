### Strategic Deep Dive (GEMINI.md Extensions)

#### 1. Objective
To unify General and Custom Agents into a single manufacturing workflow. The **Agent Factory** is where General Agents *build* Custom Agents.

#### 2. Step-by-Step Explanation
*   **Basic Insights:** Builder = General Agent. Product = Custom Agent.
*   **Advanced Insights:** **Bootstrap Moment.** Using AI to build AI. **Code as Medium.** The General Agent reads Spec (English) and writes Code (Python) that *becomes* the Custom Agent. **Efficiency.** 1000x speedup allows for "Disposable Agents."

#### 3. Examples
*   **Basic:** Input: "Script to resize images." Builder: Claude Code writes `resize.py`. Product: The script.
*   **Intermediate:** Input: "Slack bot for HR." Builder: Scaffolds Node.js, installs SDK, connects RAG. Product: "HR Helper Bot."
*   **PhD / Advanced:** **Meta-Factory.** A General Agent optimizes the Factory itself, rewriting templates to make the *next generation* of Custom Agents 10% more efficient.

#### 4. Implementation in Agentic AI
*   **Workflow:** `claude` (CLI) -> Read Spec -> Generate Code -> Run Tests -> Deploy.

#### 5. Why This Matters?
*   **Economics:** Lowers production cost to near zero.
*   **Democratization:** You don't need to know Python to build a Python Agent.

#### 6. Architecture Deep Dive
*   **Pipeline:** Spec (Input) -> Compiler (General Agent) -> Binary (Custom Agent).
