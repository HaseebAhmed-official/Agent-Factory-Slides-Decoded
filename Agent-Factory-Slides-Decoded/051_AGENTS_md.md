# Slide 51: AGENTS.md - The Project Constitution

## Core Message
**Universal Instructions for All Agents**

### Detailed Analysis (Original Context)

#### 1. What is AGENTS.md?
The "Constitution" of the project. A markdown file that tells ANY agent (Claude Code, Goose, Windsurf) how your project works.

#### 2. What's inside?
*   **Context:** "React frontend + FastAPI backend."
*   **Standards:** "Use TypeScript, Tailwind."
*   **Forbidden Actions:** "Don't delete `data/`."
*   **Tool Usage:** "Run `npm test` before committing."

#### 3. The "Aha!" Moment
"Without `AGENTS.md`, you explain the rules every time. With it, the agent 'self-onboards' instantly."

---

### Strategic Deep Dive (GEMINI.md Extensions)

#### 1. Objective
To solve the "Context Amnesia" problem. Just as humans need an Employee Handbook, Agents need a Project Handbook.

#### 2. Step-by-Step Explanation
*   **Basic Insights:** Write down your rules once.
*   **Advanced Insights:** **Universal Context Injection.** Modern coding agents (like Cursor/Windsurf) are programmed to look for this file automatically. It acts as a "System Prompt" for the repository. It standardizes behavior across *different* models and *different* developers.

#### 3. Examples
*   **Basic:** "Always use 2 spaces for indentation."
*   **Intermediate:** "Here is the schema for our Database. Use this whenever writing SQL."
*   **PhD / Advanced:** **Dynamic Constitution.** The `AGENTS.md` is generated by a "Senior Architect Agent" that reads the codebase, infers the patterns, and writes the rules for the "Junior Agents" to follow.

#### 4. Implementation in Agentic AI
*   **Location:** Root of the repo (`./AGENTS.md`).
*   **Format:** Markdown with headers like `## Coding Standards`, `## Architecture`, `## Commands`.

#### 5. Why This Matters?
*   **Velocity:** Zero-shot onboarding for agents.
*   **Consistency:** Prevents "Style Drift" where different agents write different code styles.

#### 6. Architecture Deep Dive
*   **Context Hierarchy:** `System Prompt` (Global) -> `AGENTS.md` (Repo) -> `User Prompt` (Task).

#### 7. Reflection Questions
*   *If a stranger (or robot) joined your team today, is there a single file that explains everything?*
