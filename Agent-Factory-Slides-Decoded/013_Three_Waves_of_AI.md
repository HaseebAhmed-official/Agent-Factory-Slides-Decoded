# Slide 13: The Three Waves of AI

## Core Message
**Predictive -> Generative -> Agentic**

### Detailed Analysis (Original Context)

#### 1. Core Comparison
| Feature | Wave 1: Predictive AI | Wave 2: Generative AI | Wave 3: Agentic AI |
| :--- | :--- | :--- | :--- |
| **Focus** | Analyzing data to predict outcomes. | Creating content from data. | **Autonomous actions and iterative learning.** |
| **Action** | Analyze past data -> predict future. | Creating text, images, code, videos. | **Environmental interaction & iterative learning.** |
| **Why it Matters** | Enabled data-driven decisions. | Empowered creativity and productivity. | **AI becomes proactive, managing complex tasks.** |

#### 2. Detailed Deep Dive
*   **Predictive AI (The Calculator):** Netflix recommendations, weather forecasting. It looks at patterns and tells you what *might* happen. It doesn't *do* anything.
*   **Generative AI (The Creator):** ChatGPT, Midjourney. It creates output based on a prompt. It is **Reactive**—it waits for you to ask.
*   **Agentic AI (The Executor):** Digital Employees. It is **Proactive**. It uses an **OODA Loop** (Observe, Orient, Decide, Act). It interacts with the world and self-corrects.

### Strategic Deep Dive (GEMINI.md Extensions)

#### 1. Objective
To contextualize the current technological moment. We are entering the "Third Wave" of AI. Understanding this evolution helps in predicting the capabilities and limitations of the technology.

#### 2. Step-by-Step Explanation
*   **Basic Insights:** Wave 1 analyzed. Wave 2 created. Wave 3 acts.
*   **Advanced Insights:**
    *   **Value Multiplier:** Predictive = Information. Generative = Content. Agentic = **Labor**. Labor is vastly more valuable.
    *   **Feedback Loop:** Wave 1 & 2 are Open Loop (Input -> Output). Wave 3 is Closed Loop (Action -> Result -> Correction).

#### 3. Examples
*   **Basic:** Wave 1: Grammarly (flags error). Wave 2: ChatGPT (writes essay). Wave 3: Research Agent (writes, emails professor, revises based on feedback).
*   **Intermediate:** Wave 1: IntelliSense. Wave 2: Copilot. Wave 3: Devin/Claude Code (builds app, runs tests, fixes bugs).
*   **PhD / Advanced:** Wave 3 Lab Agent: Controls a robotic pipette, synthesizes a molecule, measures the result, and updates the hypothesis autonomously.

#### 4. Implementation in Agentic AI
*   **Architecture:** Move from `User -> LLM` to `User -> Agent -> [Loop: Plan, Tool, Observe]`.
*   **Latency:** Wave 3 is slower; design UX for asynchronous "work," not synchronous "chat."

#### 5. Why This Matters?
*   **Economic Impact:** Wave 3 unlocks the "Trillion Dollar" value of Digital FTEs.
*   **Expectations:** People expect Wave 3 results from Wave 2 tools (perfect output in one shot) and get frustrated.

#### 6. Architecture Deep Dive
*   **The Loop:** OODA Loop or ReAct Pattern (Reason + Act).

#### 7. Reflection Questions
*   *Are you building a 'Chatbot' (Wave 2) or an 'Employee' (Wave 3)?*
*   *How does your business model change when you stop selling 'Content' and start selling 'Work'?*
